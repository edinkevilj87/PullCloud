Checks whether an incident report can be pulled from the cloud (6 hours after it was created, US local time). Handles all US time zones, multi-zone states and daylight saving time.

## How to install (one time)

1. Download **PullCloud.zip** below.
2. Unzip the whole **PullCloud** folder to a local folder, e.g. `C:\Tools\PullCloud` (preferably not inside OneDrive).
3. Double-click **`Start PullCloud.cmd`**.
   If the Microsoft .NET 8 Desktop Runtime is missing, the download page opens: choose **.NET Desktop Runtime 8.x → Windows → x64 Installer**, install it, then start again.
4. Double-click **`Create desktop shortcut.cmd`** – from now on use the **"Pull from the Cloud"** icon on your Desktop.
5. In the app, pick your city under **My location** and click **Save**.

**Updating:** download the new zip and unzip it over the old folder (same location) – your settings are kept.
